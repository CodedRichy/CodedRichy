## This Month (June–July 2026)

### 6. 30-Day NGO Execution Plan

Once one org says yes to your email:

**Week 1 — Discovery (build nothing)**
- Visit in person
- Watch 2–3 staff doing their actual work
- Ask: "What takes the most time every week?"
- Write it down. Do not pitch. Do not build.

**Week 2 — Scope + Build**
- Pick ONE workflow. Not a platform. One thing.
- Examples: invoice processing, attendance logging, donor acknowledgment emails, report generation, data entry from paper forms
- Build it: Claude API + FastAPI + simple UI
- Show a rough version by end of week

**Week 3 — Iterate with real users**
- Sit next to staff while they use it
- Watch where they get confused
- Fix those things
- Do not add features

**Week 4 — Deploy, train, document**
- Install it on their machine/server
- Run a 30-minute training session
- Write a one-page runbook they can follow without you
- Measure: time saved per week, tasks automated, errors reduced

**Outcome you need to document:**
- Before: [X hours/week on Y task]
- After: [Z hours/week, N% reduction]
- Quote from a staff member (ask for it explicitly)
- Photo of them using it (with permission)

This story answers Question 1 for every fellowship you apply to for the next 2 years.
